## What I'm building

### ⚡ FlashCEV

A desktop app for Chilean CEV professionals that turns hours of manual Excel work into seconds.
Built with .NET 8 + WinUI 3 on the desktop side, and a Next.js + Supabase web platform
for subscriptions, billing, and user management.

→ [flashcev.cl](https://flashcev.cl)
